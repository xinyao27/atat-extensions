# CueCue Translate

Translate what you select — or the text in a screenshot — with CueCue.

Select text anywhere and pick **Translate with CueCue** on AtAt's selection bar, or press it
on a screenshot's quick-access card. The translation appears on AtAt's result card, where you
can copy it or put it in place of the selection.

## What it touches

The extension asks CueCue through its AppleScript `translate` command, with the selected text
passed as data — never spliced into a script, and no shell involved. CueCue answers with
whichever engine and languages it is set to, the same as its own `⌘⇧Space`, so installing
CueCue and signing in is all the setup there is.

CueCue has to be installed; the button greys out and the extension's page links to
[cuecueapp.com](https://cuecueapp.com) while it is not.
