# Text Width

Converts full-width and half-width characters — letters, punctuation, katakana — either way.

## What it does

Two buttons appear beside a selection that has something to convert:

- **To half width** turns ＡＢＣ，１２３ and カタカナ into ABC,123 and ｶﾀｶﾅ.
- **To full width** does the reverse, and turns spaces into the ideographic space.
- Half-width sound marks join the kana before them (ﾃﾞｰﾀ → データ) and come apart again
  (データ → ﾃﾞｰﾀ).

Japanese half-width punctuation — ｡ ｢ ｣ ､ ･ — is not touched; it is a different
typographic choice, not a width one.

## What it touches

Only the text you selected. No folder, no network, no settings.
