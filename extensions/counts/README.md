# Count

Counts the words, characters, and lines you select.

## What it does

Select text — or reach for a clipboard card — and choose **Count**. The numbers appear in
the preview, one per line: words, characters, lines.

Han characters (including rare characters outside the basic plane), kana, and Korean syllables
each count as a word; a run of other letters or digits counts once. An apostrophe within a word
stays with it. Characters are visible grapheme clusters, so accents and joined emoji count once;
line breaks count as characters, and an empty selection has zero lines.

## What it touches

Only the text you selected. No folder, no network, no settings.
