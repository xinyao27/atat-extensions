# Count

Counts the words, characters, and lines you select.

## What it does

Select text — or reach for a clipboard card — and choose **Count**. The numbers appear in
the preview, one per line: words, characters, lines.

Chinese, Japanese, and Korean characters each count as a word of their own, the way editors
that serve both scripts count them; a run of Latin letters or digits counts once.

## What it touches

Only the text you selected. No folder, no network, no settings.
