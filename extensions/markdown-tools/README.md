# Markdown Tools

Turns what you select into Markdown lists, code, or quotes.

## What it does

Four buttons appear beside a selection:

- **Bullet list** and **Numbered list** mark each line, keeping blank lines blank and
  numbering only the lines that stay. A second click clears one level of markers.
- **Code** wraps a single line in backticks and several lines in a fenced block; the fence
  is always longer than any run of backticks inside the text. A second click unwraps it.
- **Blockquote** prefixes every line with `>`. A second click takes one level off.

Results are written back over the selection; on a clipboard card they are copied instead.

## What it touches

Only the text you selected. No folder, no network, no settings.
