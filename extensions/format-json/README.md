# Format JSON

Turns a wall of JSON into readable, two-space indentation.

## What it does

Select JSON in any app, or a clipboard card that holds some, and choose **Format JSON**. The
tidied copy is written back over the selection; on a clipboard card it is copied instead.

The button appears only on text that opens with `{` or `[`. Text that still does not parse
gets a short message rather than a broken answer.

## What it touches

Only the text you selected. No folder, no network, no settings, nothing to set up.
