# Slugify

Turns a headline into a lowercase slug fit for a URL.

## What it does

Select a title — in a document, in whatever you copied from the browser, on a clipboard
card — and choose **Slugify**. Accents fold to their plain letters, spaces and punctuation
become single dashes, and the result is written back over the words:

    Über Café: déjà vu!  →  uber-cafe-deja-vu

A selection with nothing a URL can carry gets a short message instead of an empty line.

## What it touches

Only the text you selected. No folder, no network, no settings.
