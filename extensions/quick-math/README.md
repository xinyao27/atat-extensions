# Quick Math

Works out an expression, or totals every number you select.

## What it does

Select an expression and choose **Calculate**: `12 * 34` becomes `408`, written back over
the expression. The parser takes `+ - * / ^`, parentheses, unary signs, a trailing `%`,
and `of` (`15% of 240`); it also reads `×`, `÷`, `−`, thousands separators and currency
marks, so pasted numbers work as they came.

**Sum numbers** adds every number in the selection — `3 apples, 12 oranges and 1.5 kg`
becomes `16.5`. A minus sign counts only where a digit is not in front of it, so
`Pages 10-12` totals 22 rather than −2.

Text that reads as neither gets a short message instead of a guess.

## What it touches

Only the text you selected. No folder, no network, no settings.
