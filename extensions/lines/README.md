# Lines

Sorts, reverses, or joins the lines you select.

## What it does

- **Sort lines** — alphabetical, ignoring case; two lines that differ only in case keep the
  order they were in.
- **Reverse lines** — the last line first.
- **Join lines** — one paragraph, single spaces, blank lines gone.

The buttons appear only on a selection with more than one line. Results are written back
over the selection; on a clipboard card they are copied instead.

## What it touches

Only the text you selected. No folder, no network, no settings.
